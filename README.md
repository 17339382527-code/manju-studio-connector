# 漫剧工坊 / Manju Studio

把分镜描述变成图片、镜头视频和整集成片的本地连接器。

## 能做什么

- **出图**：按镜号生成竖屏 9:16 分镜图，支持角色参考图锁定一致性
- **出片**：以定稿图为首帧生成 3–5 秒镜头
- **拼接**：按镜号顺序拼接整集，输出成片
- **自检**：检查 API Key、目录与可用模型

## 需要什么

- Node.js 22.5 及以上
- 火山方舟 API Key（默认），或你自行配置的其他模型服务
- ffmpeg（拼接用，项目内附）

## 配置

API Key 二选一：

- 写入本机 `.secrets/ark-api-key.txt`
- 或设置环境变量 `ARK_API_KEY`

密钥只保存在本机，不会上传。

## 数据与隐私

- 提示词与参考图仅发送至你配置的模型接口
- 产物与日志保存在本机
- 不收集遥测

详见 [隐私政策](privacy.md) 与 [服务条款](terms.md)。
